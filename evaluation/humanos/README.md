# Avaliações humanas

Compreensão de uma saída em frases, diagrama ou HTML, se for estudada, entra aqui. Não entra na H7, que só conta token de saída.

A H8, omissão de critério por quem escreve, também entra aqui quando houver participante. O desenho está em `HIPOTESES-v2.md`. Sem consentimento, lista fechada anterior e avaliador cego, uma nota nesta pasta não decide a H8.

As notas desta fase ainda não existem. Quando existirem, cada arquivo deve dizer a rubrica, o hash do dataset, se o braço estava oculto e como a concordância foi calculada. Não coloque nome de avaliador se a pessoa não autorizou.
